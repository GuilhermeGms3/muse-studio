# Shortcuts

Atalhos devem apoiar usuários avançados sem esconder caminhos de interface.

## Princípios

- Todo atalho tem equivalente visual.
- Atalhos globais não devem disparar ações destrutivas.
- Ações destrutivas exigem confirmação.
- Atalhos devem aparecer discretamente em tooltips, menus ou status bar.

## Atalhos Globais

| Atalho | Ação |
| --- | --- |
| Ctrl/Cmd+K | Abrir pesquisa global |
| Ctrl/Cmd+B | Alternar sidebar |
| Ctrl/Cmd+\ | Alternar Inspector |
| Ctrl/Cmd+M | Alternar metrônomo |
| Ctrl/Cmd+Shift+P | Abrir ou iniciar sessão |
| Ctrl/Cmd+Tab | Próxima aba |
| Ctrl/Cmd+Shift+Tab | Aba anterior |
| Ctrl/Cmd+W | Fechar aba atual |
| Ctrl/Cmd+1..9 | Ir para aba por posição |
| Esc | Fechar palette, menu, dialog ou cancelar foco temporário |

## Atalhos De Sessão

| Atalho | Ação |
| --- | --- |
| Space | Pausar/retomar quando foco está na sessão |
| Enter | Confirmar feedback quando formulário ativo |
| Ctrl/Cmd+Enter | Avançar atividade |
| Ctrl/Cmd+Shift+F | Finalizar sessão com confirmação |
| R | Iniciar/parar gravação quando o painel de gravação está focado |

## Atalhos De Busca

| Atalho | Ação |
| --- | --- |
| Arrow Up/Down | Navegar resultados |
| Enter | Abrir resultado |
| Ctrl/Cmd+Enter | Abrir resultado em nova aba, se já houver aba ativa diferente |
| Esc | Fechar busca |

## Atalhos De Workspace

| Atalho | Ação |
| --- | --- |
| Ctrl/Cmd+L | Focar caminho/breadcrumb futuro |
| Ctrl/Cmd+F | Buscar dentro da aba atual |
| Ctrl/Cmd+S | Salvar edição ativa |
| Ctrl/Cmd+Z | Desfazer edição local quando disponível |

## Status Bar

A status bar deve mostrar atalhos essenciais de forma rotativa ou contextual:

- Ctrl/Cmd+K busca.
- Ctrl/Cmd+B sidebar.
- Ctrl/Cmd+\ inspector.
- Ctrl/Cmd+M metrônomo.
- Ctrl/Cmd+Shift+P sessão.
