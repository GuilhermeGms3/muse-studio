# User Journeys

Este documento descreve a experiência ponta a ponta do Muse Studio. Ele segue a arquitetura obrigatória:

Macro Contexto -> Menu Contextual -> Workspace em Abas -> Módulos.

## Jornada 1: Primeiro Uso

Pergunta principal: "Por onde eu começo?"

1. O usuário abre o Muse Studio.
2. A Home aparece como estação de trabalho, não como dashboard.
3. Se o diagnóstico inicial ainda não foi feito, a Home destaca apenas uma ação principal: "Encontrar ponto de partida".
4. O usuário informa instrumento principal, nível, tempo disponível, preferências musicais, percepção rítmica, percepção auditiva e sensação técnica.
5. O sistema retorna para Home com plano inicial, objetivo atual e sugestão de primeira sessão.
6. O usuário pode iniciar sessão, explorar Skill Tree ou abrir Biblioteca.

Critério de sucesso:

- O usuário entende o próximo passo sem enxergar todas as funcionalidades.

## Jornada 2: Voltar Para Praticar

Pergunta principal: "O que praticar agora?"

1. Home mostra instrumento atual, plano de hoje, continuar de onde parou, objetivo atual e notas rápidas.
2. Usuário seleciona Praticar.
3. Menu contextual de Praticar mostra Nova sessão, Continuar sessão, Plano de hoje, Exercícios, Repertório em prática, Treino de ouvido, Metrônomo, Gravações e Objetivos ativos.
4. Usuário abre Nova sessão ou Continua sessão.
5. Sessão abre como aba de foco.
6. Durante a sessão, ferramentas aparecem por contexto: timer, BPM, notas, feedback, gravação e atividade atual.
7. Ao finalizar, o usuário registra dificuldades e melhorias.
8. Diário, habilidades e plano recebem evidências.

Critério de sucesso:

- O usuário começa a tocar rápido e só lida com detalhes quando eles são necessários.

## Jornada 3: Aprender Um Conceito

Pergunta principal: "Como isso vira música real?"

1. Usuário seleciona Aprender ou Biblioteca.
2. Menu contextual mostra Skill Tree, Mapa do Conhecimento, trilhas, conceitos em progresso ou categorias.
3. Usuário abre um conceito.
4. Conceito abre em aba própria.
5. Módulos exibem resumo, objetivos, explicação, exemplos, diagrama, erros comuns e relações.
6. Inspector mostra pré-requisitos e próximos passos.
7. Usuário abre exercício, música ou habilidade relacionada em nova aba.

Critério de sucesso:

- O conceito deixa de ser texto isolado e vira parte de uma rede de prática.

## Jornada 4: Trabalhar Repertório

Pergunta principal: "Como avanço nesta música?"

1. Usuário seleciona Praticar ou Biblioteca.
2. Abre Repertório ou busca uma música.
3. A música abre em aba própria.
4. Visão inicial mostra título, artista, instrumento, status, BPM, tom, afinação e seções.
5. Usuário seleciona uma seção.
6. Módulos revelam progresso da seção, tablatura, BPM, notas, tone preset, técnicas, escalas, gravações e habilidades ligadas.
7. Usuário gera plano de prática da música.
8. Plano pode abrir como aba ou alimentar Nova sessão.

Critério de sucesso:

- A música é tratada como objeto de estudo, não como item de lista.

## Jornada 5: Desenvolver Uma Habilidade

Pergunta principal: "O que falta para dominar isso?"

1. Usuário seleciona Aprender.
2. Abre Skill Tree ou Mapa do Conhecimento.
3. Seleciona uma habilidade.
4. Aba ou painel da habilidade mostra estado, progresso, próximo critério e exercícios ligados.
5. Inspector mostra pré-requisitos, retenção, revisões, conteúdos e músicas.
6. Usuário pratica uma evidência em sessão, exercício ou música.
7. Estado evolui apenas com critérios visíveis.

Critério de sucesso:

- O progresso parece honesto, musical e rastreável.

## Jornada 6: Compor

Pergunta principal: "Onde guardo e desenvolvo esta ideia?"

1. Usuário seleciona Compor.
2. Menu contextual mostra Projetos, Riffs, Letras, Ideias, Referências, Versões, Gravações e Preparação para Reaper.
3. Usuário abre ou cria projeto.
4. Projeto abre em aba própria.
5. Cards e painéis organizam riffs, letras, ideias, referências, versões e gravações.
6. Ferramentas de integração aparecem como módulos secundários.

Critério de sucesso:

- Capturar ideias é rápido, mas o projeto pode crescer sem virar tarefa administrativa.

## Jornada 7: Revisar Evolução

Pergunta principal: "O que mudou e o que precisa voltar?"

1. Usuário seleciona Revisar.
2. Menu contextual mostra Diário, Histórico de sessões, Evidências de habilidade, Revisões espaçadas, Progresso por instrumento, Músicas em manutenção e Exportações.
3. Usuário abre Diário ou fila de revisão.
4. Cards mostram sessões, dificuldades, melhorias e objetos relacionados.
5. Selecionar item atualiza Inspector com conexões.
6. Usuário abre habilidade, música ou exercício relacionado em aba.

Critério de sucesso:

- Revisão gera ação prática, não apenas observação passiva.

## Jornada 8: Ferramentas E Dados

Pergunta principal: "Qual ferramenta eu preciso agora?"

1. Usuário seleciona Ferramentas.
2. Menu contextual mostra Metrônomo, Gravador, Importar arquivos, Backup, Restaurar, Exportar diário, MIDI, Integrações e Preferências.
3. Ferramentas frequentes podem abrir como dock ou módulo contextual.
4. Ferramentas de dados abrem em aba Dados e Integrações.
5. Ações sensíveis pedem confirmação e indicam impacto.

Critério de sucesso:

- Ferramentas ajudam o trabalho atual sem competir com ele.
