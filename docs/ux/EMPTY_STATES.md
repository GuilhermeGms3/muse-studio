# Empty States

Estados vazios devem sugerir a próxima ação musical. Não devem explicar o produto inteiro.

## Princípios

- Mostrar o motivo do vazio.
- Oferecer uma ação principal.
- Manter o contexto.
- Evitar texto longo.
- Não transformar vazio em tela de marketing.
