# Visual Language

## Atmosfera

Muse Studio deve parecer uma mesa de trabalho limpa em um estúdio musical: módulos bem encaixados, informação suficiente, controles próximos e espaço visual para concentração.

O sistema deve ser claro e luminoso, mas não frágil. Deve usar superfícies brancas e cinzas suaves com linhas finas, contrastes precisos e pequenos acentos cromáticos.

## Paleta Conceitual

Base:

- Branco para cards e superfícies primárias.
- Cinza 50/100 para fundo geral e trilhos.
- Cinza 200/300 para bordas.
- Cinza 700/900 para texto.
- Azul discreto para foco, seleção e ações primárias.

Estados:

- Verde discreto para sucesso e sessão em bom estado.
- Âmbar discreto para atenção, revisão e pendência.
- Vermelho discreto para erro e ações destrutivas.
- Azul para informação e foco.

Contextos:

- Home: cinza azulado discreto.
- Praticar: verde suave.
- Aprender: azul suave.
- Biblioteca: violeta muito discreto ou índigo suave.
- Compor: âmbar suave.
- Revisar: ciano ou teal suave.
- Ferramentas: cinza neutro com azul técnico.

As cores de contexto devem aparecer em indicadores, bordas ativas, pequenos ícones ou etiquetas. Nunca devem dominar fundos inteiros.

## Luz E Superfície

Hierarquia de superfície:

- App background: cinza muito claro.
- Rail/sidebar: cinza frio suave.
- Workspace: cinza claro quase branco.
- Card: branco.
- Card selecionado: branco com borda contextual.
- Popover/dialog: branco elevado.
- Overlay: scrim neutro translúcido.

## Bordas

Bordas são mais importantes que sombras.

Uso:

- Separar painéis.
- Delimitar cards.
- Mostrar seleção.
- Indicar drop target.
- Definir abas.

Evitar:

- Sombras pesadas.
- Bordas coloridas em excesso.
- Separadores redundantes.

## Tipografia Visual

Tipografia deve parecer técnica e confortável:

- Texto base legível.
- Labels compactos.
- Números com tabular figures.
- Títulos curtos.
- Sem tracking negativo.
- Sem headline exagerado dentro de painéis.

## Iconografia

Ícones devem:

- Ser vetoriais.
- Usar uma única família visual.
- Ter stroke consistente.
- Ser simples e funcionais.
- Ter labels ou tooltips quando não forem autoexplicativos.

Não usar emojis como ícones estruturais.

## Densidade

Muse Studio não é minimalista. A densidade deve ser profissional:

- Compacta em chrome, sidebar e listas.
- Respirada em leitura e foco.
- Modular em cards.
- Ajustável por contexto no futuro.

## Anti-Padrões

- Fundo com orbs, blobs, bokeh ou gradientes decorativos.
- Hero visual.
- Cards enormes com métricas.
- Cores saturadas como fundo principal.
- Paleta de uma única cor dominante.
- Espaços vazios sem função.
- Layout de dashboard empresarial.
