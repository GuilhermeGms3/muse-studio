# Consistency Rules

Este documento garante que futuras telas não quebrem a identidade do Muse Studio.

## Todo Workspace Possui

- Title bar.
- Busca global.
- Indicação de instrumento.
- Tab bar.
- Área central de trabalho.
- Status bar.
- Acesso a sidebar e inspector.

## Toda Tela Possui

- Uma pergunta principal.
- Uma ação principal.
- Ações secundárias subordinadas.
- Estados vazio, carregando e erro.
- Relação clara com macro contexto.

## Toda Sidebar Possui

- Macro contexto ativo.
- Menu contextual.
- Ícones consistentes.
- Estado ativo visível.
- Possibilidade de recolher.

## Toda Aba Possui

- Título humano.
- Estado ativo/inativo.
- Fechamento quando permitido.
- Tooltip se truncada.
- Indicador de erro/modificação quando necessário.

## Todo Card Possui

- Título.
- Informação primária.
- Estado visual.
- Área de ação clara.
- Hover.
- Focus.
- Seleção quando aplicável.
- Loading/empty/error quando aplicável.

## Todo Painel Possui

- Título.
- Conteúdo delimitado.
- Relação clara com a aba.
- Ações no cabeçalho apenas quando necessárias.
- Estado recolhido se for painel colapsável.

## Toda Toolbar Possui

- Ações da aba ou seleção atual.
- Ordem de prioridade.
- Ícones consistentes.
- Tooltips para icon-only.
- Sem navegação global.

## Todo Dialog Possui

- Título claro.
- Descrição curta.
- Ação principal.
- Cancelar.
- Gestão de foco.
- Confirmação explícita para destrutivo.

## Todo Estado De Erro Possui

- O que falhou.
- O que foi preservado.
- Próxima ação.
- Indicação visual sem depender apenas da cor.

## Todo Estado Vazio Possui

- Motivo.
- Próxima ação.
- Pouco texto.
- Contexto preservado.

## Toda Cor Possui Propósito

Propósitos permitidos:

- Contexto.
- Feedback.
- Estado.
- Prioridade.
- Seleção.
- Foco.

Propósitos proibidos:

- Decoração genérica.
- Diferenciar cards sem significado.
- Preencher espaço vazio.

## Regras De Nome

Usar linguagem musical:

- Sessão.
- Repertório.
- Técnica.
- Habilidade.
- Gravação.
- Diário.
- Riff.
- Revisão.
- Afinação.
- Tom.
- BPM.

Evitar linguagem SaaS:

- Dashboard.
- Analytics.
- KPI.
- Organization.
- Team.
- Billing.
- Upgrade.
- Invite.
