# Information Architecture

Muse Studio should be organized by the user's musical context, not by the technical type of each feature.

The system contains many capabilities: home, diagnostic, plan, practice session, diary, library, skill tree, knowledge map, repertoire, exercises, ear training, metronome, projects, recordings, imports, backup, restore, preferences, and future Reaper integration. None of these should be removed. They should be placed where the user's mind expects them.

## Four-Level IA Model

Level 1: Macro Context  
The broad mode of musical intent.

Level 2: Contextual Menu  
The relevant options for the selected macro context.

Level 3: Workspace Tabs  
Concrete work surfaces opened from a menu, search result, object link, or action.

Level 4: Modules  
Cards, panels, inspector sections, docked tools, contextual controls, forms, and embedded media inside a tab.

## Primary Object Types

- Instrument: guitar, acoustic, keys, drums.
- Plan Activity: warmup, technique, theory, ear, repertoire, creative.
- Skill: musical ability with state, prerequisites, evidence, retention, and next requirements.
- Library Content: lessons, concepts, examples, diagrams, steps, mistakes, related material.
- Song: repertoire item with sections, status, techniques, scales, notes, and progress.
- Song Section: independent study unit inside a song.
- Exercise: technical drill with BPM, accuracy, difficulty, instructions, and variations.
- Ear Training Attempt: response evidence for auditory training.
- Practice Session: focused time block with activities, notes, timer, and completion state.
- Activity Result: feedback evidence for a specific session activity.
- Session Summary: post-practice review.
- Recording: audio evidence attached to a context.
- Project: creative workspace with riffs, lyrics, ideas, references, and versions.
- Journal Entry: historical record of practice.
- Imported File: local audio, MIDI, MusicXML, or Guitar Pro asset.
- Preferences and Diagnostic: personal calibration data.

## Recommended Macro Contexts

- Home
- Praticar
- Aprender
- Biblioteca
- Compor
- Revisar
- Ferramentas

Home is a re-entry station, not a dashboard category. It can exist as the default tab and should not compete with the other macro contexts.

## Cross-Context Relationships

Skills connect to:

- Lessons
- Exercises
- Songs
- Prerequisites
- Next skills
- Practice evidence
- Reviews

Songs connect to:

- Sections
- Techniques
- Scales
- Practice plans
- Recordings
- Journal entries
- Projects

Sessions connect to:

- Plan activities
- Instrument
- Skill evidence
- Exercise attempts
- Repertoire work
- Recordings
- Journal entries
- Session summaries

Projects connect to:

- Riffs
- Ideas
- Lyrics
- Versions
- References
- Recordings
- Future Reaper material

## IA Rule

Every object should answer:

- Where does it belong as a primary context?
- Where can it appear as supporting context?
- What opens as a tab?
- What stays as a module?
- What appears only through search, inspector, or contextual action?
