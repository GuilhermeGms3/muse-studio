# Conceptual Roadmap

This roadmap is conceptual. It describes product direction, not implementation tasks.

## Phase 1: Navigation Reframing

Goal: make Muse Studio feel like a workspace organized by mental context.

Key outcomes:

- Define macro context navigation.
- Replace flat feature exposure with contextual menus.
- Preserve all current routes and capabilities.
- Formalize tab-opening behavior.
- Make Home a re-entry station.
- Make global search a universal direct path.

## Phase 2: Object-Centered Workspaces

Goal: make musical objects feel like first-class work surfaces.

Key outcomes:

- Songs open as rich object tabs.
- Skills open with evidence, prerequisites, and related material.
- Lessons connect to diagrams, exercises, and songs.
- Projects support riffs, lyrics, references, recordings, and versions.
- Diary entries link back to the work that produced them.

## Phase 3: Progressive Disclosure And Inspector

Goal: reduce visible complexity without reducing power.

Key outcomes:

- Inspector follows selected object.
- Advanced fields move out of default view.
- Modules use cards and panels consistently.
- Docked tools become context-aware.
- Empty states guide next action.

## Phase 4: Review And Mastery System

Goal: make progress feel honest and musically meaningful.

Key outcomes:

- Strengthen review queue.
- Improve skill evidence history.
- Show retention and due reviews.
- Connect song completion to skill progress.
- Connect exercise attempts to next requirements.
- Make session summaries actionable.

## Phase 5: Library And Knowledge Map Expansion

Goal: make the user feel they are exploring a musical knowledge graph.

Key outcomes:

- Expand map beyond Skill Tree route behavior.
- Improve category browsing.
- Add better related-object pathways.
- Support favorites, playlists, downloads, and artist grouping.
- Make imported files part of the knowledge system.

## Phase 6: Creative Studio Growth

Goal: make composition feel native, not bolted on.

Key outcomes:

- Project tabs become richer creative environments.
- Riffs, lyrics, references, recordings, and versions become easier to capture.
- Creative work connects to skills, songs, and practice history.
- Prepare project metadata for future DAW workflows.

## Phase 7: Advanced Tools And Integrations

Goal: expand power while keeping the workspace calm.

Key outcomes:

- Improve recording analysis.
- Add tuner when appropriate.
- Deepen MIDI support.
- Improve import parsing for music files.
- Prepare Reaper integration for projects, takes, BPM, markers, and study associations.

## North Star

Muse Studio becomes a personal Music OS: a place where learning, practicing, creating, recording, reviewing, and organizing music feel connected inside one professional workspace.
