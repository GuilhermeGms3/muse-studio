# Jobs To Be Done

## Primary Jobs

When I open Muse Studio, I want to immediately understand what musical work deserves my attention, so I can begin practicing without rebuilding my plan from memory.

When I practice, I want a focused session with timer, instrument, BPM, current activity, notes, and feedback, so I can stay immersed and still produce useful progress data.

When I study a concept, I want to see its explanation, examples, diagrams, mistakes, related skills, exercises, and songs, so I understand how the concept becomes playing ability.

When I learn a song, I want to break it into sections and attach techniques, scales, notes, BPM, tablature, and recordings, so I can improve the song piece by piece.

When I train a skill, I want prerequisites, current state, evidence, target criteria, and next skills, so progress feels grounded in real mastery.

When I finish practicing, I want to capture what improved, what was difficult, and what to do next, so tomorrow's practice starts smarter.

When I compose, I want to keep riffs, lyrics, references, ideas, and versions together, so creative fragments become real projects.

## Secondary Jobs

When I am lost, I want global search to find modules, contents, songs, exercises, and skills, so navigation does not depend only on menu memory.

When I change instruments, I want the workspace to adjust its relevant material, so guitar, acoustic, keys, and drums do not blur together.

When I import files, I want them stored locally and associated with musical contexts, so audio, MIDI, MusicXML, and Guitar Pro files become part of my study system.

When I review progress, I want meaningful history and evidence, so I can see patterns without being reduced to corporate-style analytics.

When I need a tool, I want it available as a contextual module, inspector item, dock, or command, so the interface stays calm until the tool matters.

## Emotional Jobs

I want Muse Studio to feel like my studio, so returning to practice feels inviting rather than administrative.

I want the system to feel powerful, so I trust it can hold my entire musical life.

I want progress to feel honest, so mastery reflects practice, consistency, accuracy, BPM, repertoire, reviews, and judgment.

I want exploration to feel rewarding, so discovering a connection between theory, skill, and song feels natural.
