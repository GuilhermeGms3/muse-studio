# User Flows

## Primary Flow: Start Today's Practice

1. User opens Muse Studio.
2. Home shows the current instrument, today plan, continue point, current objective, quick notes, and recent context.
3. User selects Praticar.
4. Contextual menu shows Nova sessão, Continuar sessão, Plano de hoje, Exercícios, Repertório em prática, Treino de ouvido, and Metrônomo.
5. User opens Nova sessão.
6. Session opens as a focused tab or focus workspace.
7. User practices each activity with timer, BPM, notes, and contextual tools.
8. User records feedback for each activity.
9. User finishes the session.
10. Muse Studio creates journal evidence and updates relevant skills, plan activity status, and session summary.

## Primary Flow: Learn A Concept

1. User selects Aprender or Biblioteca.
2. User opens Skill Tree, Mapa do Conhecimento, or a library category.
3. User selects a concept.
4. Concept opens in a tab.
5. The tab shows modules for explanation, examples, diagrams, steps, common mistakes, related skills, exercises, and songs.
6. User opens a related exercise or song in another tab when ready.
7. Inspector shows prerequisites and next steps.

## Primary Flow: Practice A Song

1. User selects Praticar.
2. User opens Repertório em prática or searches for a song.
3. Song opens as its own tab.
4. The song tab shows overview, sections, techniques, scales, notes, BPM, tuning, progress, and recordings.
5. User selects a section.
6. Section modules reveal tablature, BPM, tone preset, difficult notes, related skills, and recordings.
7. User generates a practice plan from the song.
8. The plan appears in Plano de Hoje or starts a focused session.

## Primary Flow: Build A Skill

1. User selects Aprender.
2. User opens Skill Tree or Mapa do Conhecimento.
3. User selects a skill node.
4. Skill opens with state, progress, prerequisites, next requirements, related content, exercises, songs, and next skills.
5. User records evidence through practice session, exercise attempt, song completion, review, BPM, accuracy, or self-rating.
6. State changes only when criteria justify the transition.

## Primary Flow: Compose A Project

1. User selects Compor.
2. User opens Projetos or creates a project.
3. Project opens as a tab.
4. Modules show riffs, lyrics, ideas, references, versions, recordings, and notes.
5. User captures fragments quickly without leaving the project.
6. Future Reaper integration appears as a contextual integration area, not as a dominant feature.

## Secondary Flow: Diagnose Starting Point

1. New or returning user opens Home.
2. If onboarding is incomplete, Home offers Diagnóstico inicial.
3. Diagnostic asks instrument, level, session time, genres, artists, songs, rhythm baseline, ear baseline, and technique baseline.
4. Muse Studio updates preferences and starting skills.
5. User returns to Home with a clearer first plan.

## Secondary Flow: Import Musical Material

1. User selects Biblioteca or Ferramentas.
2. User opens Importação or Dados e Integrações.
3. User imports audio, MIDI, MusicXML, or Guitar Pro.
4. Imported file appears as local material.
5. User attaches it to a song, lesson, project, session, or future review context.

## Secondary Flow: Review Progress

1. User selects Revisar.
2. User opens Diário, Histórico de sessões, Evidências de habilidade, or Revisões espaçadas.
3. User reviews entries by date, instrument, song, skill, exercise, or project.
4. User identifies patterns and opens related tabs for action.
5. Review leads back to practice, learning, or repertoire work.
